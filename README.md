# EMSC2010 – Week 2 Practical 2: Collaborating with GitHub and Colab

This repository contains the template Jupyter notebooks for **Week 2 Practical 2** of *EMSC2010: Data Science for Earth System Scientists* at the Australian National University.

Building on the GitHub/Colab workflow introduced in Week 2 Practical 1, this session focuses on **collaborative editing** — sharing a notebook with a partner or group via Google Drive and committing combined edits back to GitHub.

---

## Notebooks

### Notebook 1 – Collaborating with a Partner (`NB1`)

This notebook is a hands-on exercise in pairwise collaboration. Students open the notebook in Colab, save a copy to Google Drive, perform a small test calculation, and then **share the Drive copy with a partner** (via Gmail). The partner opens the shared notebook and adds their own edit. Once both edits are visible, either student commits the combined notebook back to GitHub — demonstrating how Google Drive enables real-time shared editing ahead of a GitHub commit.

**Key concepts:** Sharing Colab notebooks via Google Drive, real-time collaborative editing, committing shared work back to GitHub

**Libraries:** None — this notebook contains no analysis code

---

### Notebook 2 – Group Fermi Estimation Problem (`NB2`)

This notebook extends the collaboration exercise from NB1 to a small group. After sharing the notebook with all group members via Google Drive, the group works together to solve a **Fermi estimation problem** — an order-of-magnitude estimate of a quantity that is difficult to measure directly (the example provided estimates the mass of the world's oceans). The group writes and runs the estimation code collaboratively, then commits the result back to GitHub.

**Key concepts:** Group collaboration via Google Drive, Fermi estimation (order-of-magnitude reasoning), committing group work back to GitHub

**Libraries:** None specified — groups add any packages required for their estimation

---

## Getting Started

This is a **template repository**. To begin working on the notebooks:

1. Click **"Use this template"** at the top of this page to create a copy of the repository in your own GitHub account.
2. Open a notebook from your copy of the repository and click the **"Open in Colab"** badge at the top of the notebook to launch it in Google Colab.
3. Before submitting, replace the `uxxxxxxx` placeholder in the filename with your ANU student UID.
4. Follow the in-notebook instructions to save a copy to Google Drive, share it with your partner/group, collaborate on the edits, and commit the result back to your GitHub repository.
